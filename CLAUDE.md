# EarBuddies

A mobile-first PWA that teaches young children to identify chords by ear
(Eguchi Chord Identification Method).

See `README.md` for setup, checks and layout.

## Manager/Worker Model

**Involvement level:** 1 — Interfaces
Escalate new dependencies, changes to the profile/export file format or its
migrations, the shape of the persisted store, and anything altering the
instrument or curriculum content contracts. Module layout, naming and internal
structure stay with the worker.

**Testing involvement:** autonomous

**Required skills**
- Reviewers: `superpowers:verification-before-completion`

Set 2026-09-15. Change by telling the Engineering Manager.
